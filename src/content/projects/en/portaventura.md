At Randstad Digital I work on PortAventura World's digital ecosystem. The flow I work on most is
buying tickets: choosing the date and the party, adding products and extras, reviewing the summary
and paying, the same on the web and inside the app.

## What I do

- React and TypeScript architecture for each season's demand peaks.
- WebView-based apps: the same code in the browser and in the app.
- Core Web Vitals optimization so every step loads fast.
- Complex flow state with Zustand and real-time data with the backend teams.
- Technical standards, mentoring, code reviews and automated testing.
